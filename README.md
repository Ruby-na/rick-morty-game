# Rick Portal Escape 🎮

A 2D platformer game built using Python and Pygame inspired by Rick-style portal adventures.

## Features
- Player movement and jumping physics
- Moving enemy with collision detection
- Spike obstacles
- Collectible items with scoring system
- Sound effects (jump, collect, hit)
- Portal win condition
- Game over and restart system

## Controls
- Arrow Keys → Move
- Space → Jump
- R → Restart (after game over)

## How to Run
pip install pygame  
python main.py
